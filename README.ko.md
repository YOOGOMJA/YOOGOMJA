## 일하는 방식

- 제품의 완성도와 팀의 전달 속도를 함께 봅니다.
- 반복되는 작업은 자동화, 템플릿, 공용 규칙으로 바꾸는 편입니다.
- 성능, 배포 안정성, 코드 탐색 비용 같은 눈에 덜 보이는 문제도 제품 품질의 일부라고 봅니다.
- AI는 보여주기용이 아니라 구현 시간, 분석 비용, 협업 비용을 줄이는 실용적인 도구로 사용합니다.
